电子礼金簿 · 使用说明
=====================

【内容】
  1. index.html  —— 网页版电子礼金簿（推荐用这个）
  2. 电子礼金簿.xlsx —— Excel 版（汇总 / 礼簿扫描件 / 法院同事 / 请客名单 / AI复核 五个表）
     （第18页底部的落款行「总理事/记账人/礼金总额」已剔除，不计入礼金）
  3. 礼金簿_files/ —— 扫描件原件图（19 页）+ AI复核缩略图
  4. 电子礼金簿_单文件版.html —— 图片全部打包进一个文件，方便发微信／AirDrop

【数据来源】
  · 法院同事 222 条：来自「礼金登记.xlsx」，已去掉姓名+金额完全重复的记录，数据是准的。
  · 礼簿（扫描件）329 条：来自「扫描文稿.pdf」19 页手写礼簿。这是机器识别的草稿，
    姓名和金额都会有错字（手写体识别本来就有限），需要对着原件核对。

【这一版做了什么：AI 复核】
  除了 OCR，还用了视觉模型把每条记录的原行截图单独再看一遍（gemma 整行 / gemma 特写 /
  本地 PP-OCR 特写 / qwen 整行，共 4 路），并与 OCR 读法交叉比对：
    · 完全一致的 222 条：标「一致」，不必看。
    · 明显比 OCR 更可信的 53 条（OCR 只认出一票、或读出来的字根本不像名字）：已采用模型读法，
      标「AI修正」，并在复核页给出「改回原件读法」，看一眼不对就点回去。
    · 模型有别的读法、但 OCR 证据（多个预处理版本一致）也强的 35 条：保留 OCR 读法，
      把模型读法列成候选，点一下即可采纳。
    · 另有 32 条标了「分歧」（两种读法势均力敌），也一并列着，优先扫一眼。
  共 109 条列进「AI 复核」页，每条都配原行截图，左看截图右点按钮，一条 2 秒。

【怎么核对最快】
  打开 index.html → 顶部「AI 复核」：
    · 每条一张卡片：上面是该行原件的截图，下面是原件 OCR 读法 + 各模型读法 + 候选。
    · 点「采用 AI 建议 X」/「改回原件读法 X」/「保持原样」，或者直接在输入框里填正确姓名。
    · 筛选项：待复核 / AI建议不同 / 金额被修正 / 多源分歧 / 全部 / 已处理。
    · 处理过的条目会变灰并记入「已处理」，顶部标签上的数字会减少，做到 0 就完了。
  再到「扫描件核对」页：
    · 左边是原件，右边是这一页识别出来的记录，直接点着改名字和金额（名字框点开会弹出候选）。
    · 绿条表示"这一节金额跟原件底部合计对得上"；红条会告诉你差多少，按差额去改。
    · 金额后面带 * 的，是原件没认出来、由该页合计推算出来的，重点看这些。
    · 一页核对完点「标记本页已核对」，页码变绿。
  全部改完后 →「数据备份」→「导出 Excel (CSV)」或「导出 JSON 备份」留档。

【看几个符号】
  · 姓名显示「？」：机器没认出来（金额是从该页合计推的，为了不破坏合计先占位），照原件填上。
  · 金额后面带 * ：原件上这一格没认出来，按该页底部合计反推，优先核对。
  · 名字后面带「AI…」标签：这条有 AI 复核意见，标题鼠标悬停可看详情。

【分组（自己定）】
  顶部「分组」条 + 「数据备份 → 分组管理」：
    · 分组随便建：新建 / 改名 / 上下排序 / 删除（删组不删记录，自动变「未分组」）。
    · 明细表每一行右边都有分组下拉，点一下就能换组；勾选多条可批量「归入该分组」。
    · 「请客名单」用同一份分组，顶部显示「按我的分组：X 人」。

【对账体检（加起来对不上就查这里）】
  「扫描件核对」页底部会列出没对上的节：「第N页 第K节 差X元」，点一下直接跳过去。
  「数据备份」页有体检表：全部合计 / 已归页记录合计 / 每节「已录 vs 原件合计」。
  编辑记录时可改「页码 / 节」，归错页的记录搬回去后对账立刻重算。

【手机上看（每天都能看）】
  · 手机浏览器打开 https://yueairhui.top/lijinbu/ （备案域名，微信里点开也正常）。
    iPhone Safari 里点「分享 → 添加到主屏幕」，以后像 App 一样点开。
  · 手机和电脑是各自独立保存的。想让手机用电脑上的最新数据：
    在电脑上「导出 JSON 备份」→ 把 json 发给助手，助手会更新云端 → 手机上点「☁️ 同步云端版本」。
  · 手机上误点了同步也别慌：点「↩︎ 撤销同步」能找回同步前的本机版本。

【注意】
  · 所有修改自动存在这台电脑的浏览器里（localStorage），刷新、重启都不会丢。
  · 但换电脑／换浏览器就打不开旧数据了，所以核对完记得导出一份备份。
  · 用 file:// 直接双击打开时，个别浏览器不让页面存数据，此时页面顶部会出现红字警告——
    这时请在浏览器里访问上面的 https 地址（能正常保存）。
  · 「明细」页可搜索、按金额筛选、排序、手动添加；「统计」页看金额分布和单笔最高。
